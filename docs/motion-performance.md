# 开屏粒子性能优化

基线版本：`a90db50`。保留星空凝字、鼠标扰动、彗星轨迹、变向消散和名称介绍处停靠。

## 实现变化

- 移动星点、文字粒子和星尘统一写入可复用的浮点缓冲区，由 Web Worker 使用 OffscreenCanvas / WebGL 批量绘制。GPU 上下文初始化、着色器编译和绘图缓冲区调整均在后台线程完成。
- 帧数据通过可转移缓冲区来回复用；绘制端忙碌时保留最新场景，不积压过期画面。
- 完整字形仍以设备原生分辨率缓存。粒子数量决定运动细节，字形清晰度由完整蒙版保证。
- 字形蒙版按粒子覆盖率的变化增量累计，不再每帧反复遍历所有文字粒子。尚未开始入场的粒子不参加更新，归位且完全融入字形的粒子退出活跃集合。
- 入场引导使用空间查询和字形单元复用；清除重复初始化、重复排序和不必要的字体重采样。
- 开场分级反馈从两秒缩短至约 400 毫秒，降档会实际移除多余粒子的计算任务，同时平滑更新蒙版。
- 静止尾迹复用已绘制画面；彗星位置使用 CSS transform，减少布局失效；删除已不使用的体积星体和颜料形态 SVG。
- 不支持 OffscreenCanvas、Worker 下载失败或 GPU 上下文丢失时使用缓存圆点图集回退到 Canvas 2D；上下文恢复后自动切回。

## 视觉密度与不同刷新率

- 运动中的文字粒子由 GPU 追加稳定的微粒伴星。同一个物理粒子产生两到四层不同方向、大小和色温的细小星尘；主线程仍只计算原有粒子的轨迹与交互，文字固化时伴星随蒙版自然退场。
- 页面从实际 `requestAnimationFrame` 间隔估计显示器刷新率，并选择均匀的整数分频。全质量下常见结果包括 60→60、90→90、120→60、144→72、165→82.5、180→90、240→80 FPS；性能降档会同时降低目标频率。
- 性能反馈同时观察主线程耗时、动画回调延迟和渲染 Worker 连续来不及交帧的情况。一次字体或显卡初始化抖动不再永久锁定低档，后续稳定动画可以恢复细节。
- 字形蒙版限制为每秒最多 36 次更新，粒子运动仍按目标帧率进行。Head 离场过程复用开始时测得的版面位置，星尾细丝按相近画笔状态合批，减少滚动期间的布局同步与描边提交。

## 首轮优化的同配置采样

以下数据记录提交 `dfaed44` 的首轮结果，作为后续改动的历史基线。Edge 152.0.4191.66，2550 × 1275，DPR 1.25，默认动态模式，首次打开首页。每次运行使用新的浏览器页面，观察开场及其后约 1.4 秒。CPU 限速通过 CDP 设置。

| 主线程指标 | 原实现 / 常规 CPU | 优化后 / 常规 CPU | 原实现 / 4× CPU 限速 | 优化后 / 4× CPU 限速 |
| --- | ---: | ---: | ---: | ---: |
| 开场动画回调平均耗时 | 13.49 ms | 2.92 ms | 103.44 ms | 16.08 ms |
| 开场动画回调 P95 | 34.60 ms | 9.30 ms | 201.30 ms | 36.60 ms |
| 最长主线程长任务 | 254 ms | 150 ms | 998 ms | 429 ms |
| 整个观察期长任务数 | 3 | 1 | 43 | 13 |
| 低档下参与运算的文字粒子 | 17,868 | 约 2,550 | 17,868 | 约 2,600 |

回调样本来自 `tick`，包含帧率控制跳过的回调。以上衡量主线程占用，后台 GPU 耗时不在回调计时内；实际帧率还受 GPU、刷新率与浏览器调度影响。粒子布局带有随机性，单次采样用于定位瓶颈与确认改善，不能代表所有设备。

## 手动复验

使用已有 Playwright 安装；也可通过环境变量 `PLAYWRIGHT_MODULE` 指定其模块路径，无需将其加入站点运行时依赖。

```sh
npm run dev -- --background
node scripts/profile-motion.mjs --rate=1 --summary=true
node scripts/profile-motion.mjs --rate=4 --summary=true
node --test tests/*.test.js
npm run build
node scripts/check-motion-browser.mjs
```

性能探针只在测试浏览器中临时注入，不随网站发布。浏览器复验针对构建产物，覆盖十层凝字、扰动与恢复、重播、GPU 上下文丢失与恢复、停靠、减少动态、移动端 2D 回退及 Worker 下载失败。
